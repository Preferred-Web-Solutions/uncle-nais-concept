# Uncle Nai's Thai and Sushi — concept preview

A one-page concept site built by Preferred Web Solutions for Uncle Nai's Thai
and Sushi, 223 Main Street, Milford, Ohio.

This is a design proposal, not the restaurant's official website. Every page
carries that notice. The site is marked `noindex` and `robots.txt` disallows
crawling, so it should not appear in search results.

Menu text and prices are transcribed from the restaurant's own printed menu
(checked 12 October 2026). The logo belongs to Uncle Nai's Thai and Sushi and
appears here only so the owner can see their own brand in place.
